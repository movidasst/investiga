# Expediente MAC

Simulador didáctico de la Academia Movida de SST para investigar accidentes de trabajo con el Método del Árbol de Causas. Funciona con HTML, CSS y JavaScript, sin dependencias ni servicios externos. El avance se guarda por caso en el navegador.

## Casos

- **La banda en movimiento**. Adaptación del informe de demostración ficticio DEMO-AT-2026-001 de la Academia.
- **El caso del silo 6**. Adaptación didáctica del [estudio de Sanmiquel y colaboradores, ORP 2019](https://www.prevencionintegral.com/canal-orp/papers/orp-2019/analisis-accidente-sector-minero-mediante-metodo-arbol-causas-metodo-feyer-williamson). El cierre enlaza la figura 7 para el debate.

Las dos ilustraciones recrean los escenarios con fines didácticos. El logo es el archivo oficial aportado por La Movida de SST+.

## Ejecutar

Abre `index.html` en el navegador o ejecuta `python3 -m http.server 8000` desde la raíz. Para GitHub Pages, configura la publicación desde `main`, carpeta `/ (root)`. Todas las rutas de archivos del juego son relativas.

`casos.js` contiene las evidencias, afirmaciones, relaciones y medidas de cada caso.
